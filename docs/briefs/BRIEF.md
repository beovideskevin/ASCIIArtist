# Create a basic application structure

The ASCII Artist application needs to have a basic structure. We need to create the boilerplate for the application.

The title of the application will be ASCII Artist.

The application will only run in portrait mode.

Use the default icons from the folder assets/images. They will be replaced later.

Add a canvas element that covers the whole screen and it is centered. The canvas should be responsive and cover the whole screen no matter the width and height of the screen.
